# 배포·런칭 체크리스트 (기능 개발 외)

기능 백로그는 [[feature-gaps]]가 정본. **이 문서는 "배포를 결정한 시점"에 여는 것**이며,
그 전까지는 착수하지 않는다(2026-08-13 사용자 결정 — 당분간 배포하지 않음).

여기 있는 항목은 대부분 **코드가 아니라 계약·법무·인프라 설정**이라 사용자만 진행할 수 있다.

---

## 1. 외부 계약·심사 (리드타임 있음 — 배포 결정 시 가장 먼저)

| # | 항목 | 막고 있는 기능 |
| --- | --- | --- |
| L-1 | 토스페이먼츠 실키 발급 → `.env` 반영 | 실결제 전체 |
| L-2 | 카카오 비즈 앱 전환(외부 심사) | 갭 #37 카카오 로그인, #15 알림톡 |
| L-3 | 카카오 알림톡 채널 계약(건당 과금 — "무료 범위만" 원칙과 충돌 여부 판단) | 갭 #15 |
| L-4 | 토스 빌링키 발급 | 갭 #16 크리에이터 카드 등록(안티프로드) |
| L-5 | 통신판매중개업 신고 · 사업자 등록 | 약관 확정(L-8) |

## 2. 인프라·운영 설정

| # | 항목 | 비고 |
| --- | --- | --- |
| L-6 | cron 3종 등록 — `scripts/order_deadline_sweep.py`(5분) · `scripts/campaign_deadline_sweep.py`(10분) · `scripts/notification_outbox_worker.py`(1분) | **유닛 파일 작성은 에이전트가 도울 수 있음**(launchd/systemd/crontab + 로깅·중복 실행 방지) |
| L-7 | 업로드 디렉토리(`UPLOAD_DIR`) 영속 볼륨 확인 · 백업 | 포트폴리오·스크린샷·납품물이 여기 쌓임 |
| L-8 | 약관·개인정보 처리방침(`/terms`·`/privacy`) 법률 검토 | 현재 템플릿 수준 — L-5 이후 |
| L-9 | 도메인·HTTPS·프로덕션 `.env` 분리 | |
| L-10 | DB 백업·마이그레이션 절차 확정 | 운영 데이터 유실 방지 |

## 3. 실데이터 확보 후 보정 (런칭 직후 재방문)

- 단가 계산기 기준 단가 — `www/components/pricing-calculator.tsx` 상수. 현재 시장 참고치, 실거래가 확보 시 보정.
- vetting 기준치 — `VETTING_MIN_FOLLOWERS`(1,000) · `VETTING_MIN_ENGAGEMENT_PERMILLE`(10)가
  실제 가입자 분포에 맞는지 재검토.
- 페르소나 랜딩 문구(`www/lib/personas.ts`) 다듬기 + **실사례 확보 시 케이스 스터디 추가**
  (실적 없는 성과 수치는 만들지 않는다).

## 4. 런칭 이후에만 의미가 생기는 기능 (조건 대기)

조건이 풀리기 전에는 재제안하지 않는다.

- **갭 #6·18·19·20** — 구독 플랜 도입 이후에만 의미. 유저 확보 후 재개.
- **갭 #15·37 + #16의 카드 등록** — 위 L-2·L-3·L-4 묶음.
- **갭 #30** — 팀 워크스페이스(#18)와 함께.
- **갭 #13의 에이전시·엔터프라이즈 랜딩** — #18 구현 후(없는 기능 광고 방지).
- **갭 #9 잔여(팔로워·참여율 필터)** — #14 데이터가 실제로 쌓인 뒤.
- **갭 #39~44** — 명시적 보류(LLM 브리프·매칭·다통화·앱 딥링크·API 성과수집·세금계산서).
