## P0 — 돈이 흐르지 않거나 새는 지점

- [x] **1. 크리에이터 인출(pay-out)** — ✅ 2026-08-11 구축. order `withdrawal_request`
  슬라이스(잔액 차감 원자적, advisory lock) + 허브 `WithdrawalSettlementPort` +
  admin 지급완료/실패(복원). 이체 실행은 운영자 수동 — 지급대행 API 연동 시 구현체 교체.

  1번과 함께 구축. **지급명세서 서류 발급·연간 집계는 잔여.**
- [x] **3. 납품물 업로드(콘텐츠 제출 실체)** — ✅ 2026-08-11 구축. order
  `deliverable_submission` 슬라이스(파일·링크, append-only) + `submit`은 납품물 ≥1건
  필수(도메인 강제) + 주문 상세 납품물 섹션(크리에이터 업로드·브랜드 열람).
- [ ] **4. 주문 취소(양측 합의) + 분쟁 중재** — 🟡 절반: 양측 합의 취소(요청→상대 동의→
  CANCELLED+전액 크레딧 환불, 거부→계속)는 2026-08-11 구축. **admin 분쟁 중재 잔여.**
- [x] **5. 크레딧으로 재결제** — ✅ 2026-08-11 구축. CREDIT_SPENT 차감성 기입 + 허브
  `CreditBalancePort` + 체크아웃 `use_credit`(적용액=min(잔액,총액), PG 청구액=차액,
  전액 크레딧은 결제창 생략) + 주문 생성 시 advisory lock 잔액 재검증·원자 차감.
- [x] **5-1. (보안) 로그아웃 시 백엔드 리프레시 토큰 폐기** — ✅ 2026-08-11 구축.
  auth `logout` 슬라이스(`POST /auth/tokens/logout`, Redis GETDEL 멱등 폐기) +
  BFF logout이 쿠키 삭제 전에 호출(백엔드 불통 시에도 쿠키는 삭제).
