## 1. 서비스 개요

**Collabstr**는 브랜드와 인플루언서/UGC 크리에이터를 연결하는 **셀프서브(self-serve) 인플루언서 마케팅 마켓플레이스**다.

- 포지셔닝 문구: "Run Influencer Marketing from First Search to Final Payment" — 검색부터 결제까지 전 과정을 한 플랫폼에서 처리
- 모델 요약: **"인플루언서 협찬의 Fiverr"**. 크리에이터가 가격이 공개된 패키지(상품)를 등록하고, 브랜드가 이커머스처럼 장바구니에 담아 구매
- 자체 공개 규모 지표 (공식 홈페이지 기준):
  - 크리에이터 110만+ (1.1m+)
  - 등록 브랜드 500,000+
  - 납품된 콘텐츠 100,000+
  - 활성 브랜드의 5성 리뷰 48,000+
- 트러스트 로고: McDonald's, United Nations, ClickUp, Wealthsimple, Hopper, OrangeTheory Fitness
- 지원 플랫폼: Instagram, TikTok, YouTube, Twitter(X), Twitch, Amazon, UGC(플랫폼 무관 콘텐츠 납품)
- 니치 카테고리 26개: Lifestyle, Beauty, Fashion, Travel, Health & Fitness, Family & Children, Food & Drink, Comedy & Entertainment, Animals & Pets, Art & Photography, Music & Dance, Model, Education, Entrepreneur & Business, Adventure & Outdoors, Technology, Athlete & Sports, Gaming, Healthcare, Celebrity & Public Figure, Actor, Automotive, LGBTQ2+, Skilled Trades, Vegan, Cannabis

## 3. 플랫폼 전체 기능 분석

공식 사이트가 제시하는 워크플로우는 7단계다: **01 Creator Discovery → 02 AI Campaign Briefs → 03 Order Management → 04 Global Payments → 05 Reporting → 06 Team Workspace → 07 Creator CRM**

### 3.1 크리에이터 검색 (Search Creators / Find & Hire)

- 110만+ 크리에이터 대상. 모든 크리에이터는 입점 전 검증(vetted) 절차를 거침
- 필터: 플랫폼, 니치(26개), 위치, 팔로워 수, 참여율, 가격대
- 고급 필터(유료): 오디언스 연령, 언어, 인종(ethnicity) 등
- 큐레이션 검색 프리셋: Rising Instagram Stars(팔로워 1만~10만), Rising TikTok Stars, Most Viewed, Under $250, UGC, Fashion, Beauty, Health & Fitness — URL 쿼리 파라미터 기반
- 쇼트리스트 저장·비교 기능
- **검색 자체는 무료** (구독 없이 검색 → 직접 고용 → 결제 가능)

### 3.2 캠페인 브리프 & 아웃리치 (Campaign Briefs / Post Campaigns)

- 직접 고용(Direct hire)과 반대 방향의 **역경매/공고 모델**: 브랜드가 브리프를 올리면 매칭되는 크리에이터가 자기 견적과 함께 지원
- **AI 브리프 생성**: 캠페인을 설명하면 브리프 자동 생성
- **Instant Creator Match**: 캠페인에 적합한 크리에이터 자동 서페이싱
- 타겟팅: 니치, 위치, 인구통계
- 공식 FAQ 기준, 대부분의 캠페인은 게시 후 1시간 내 첫 지원 수신
- 캠페인 게시는 **유료 플랜 전용** (Pro: 월 1건, Premium: 무제한)

### 3.3 채팅 & 협상 (Creator Chat & Management)

- 결제 전 크리에이터와 직접 메시징
- 딜리버러블, 타임라인, **사용권(usage rights)**, 수정 횟수를 사전 합의
- 팀원을 대화에 초대해 협업 검토 가능
- 모든 커뮤니케이션이 플랫폼 내부에 기록(분쟁 시 근거)

### 3.4 에스크로 결제 & 글로벌 지급 (Secure Global Payments / Approve & Pay)

- **주문 확정 시점에 대금이 에스크로에 예치**되고, 브랜드가 콘텐츠를 검수·승인해야 크리에이터에게 지급
- 승인 전까지 자금 미지급 = 브랜드의 "돈만 떼임" 리스크와 크리에이터의 "일하고 못 받음" 리스크를 동시 해소
- **150개국 지급 및 세금 서류(tax forms) 자동 처리**
- 자동 청구·빌링 문서화

### 3.5 성과 추적 & 리포팅 (Performance Tracking / Track & Report)

- 게시된 포스트를 자동 추적(수동 리포팅·서드파티 툴 불필요)
- 포스트 단위(post-level) 도달·참여·ROI 실시간 대시보드
- 추적 한도: Pro 동시 5개 / Premium 동시 15개, **포스트당 최대 3주간 추적**
- 참여율·가짜 팔로워 리포트: Pro 월 20건 / Premium 월 50건

### 3.6 팀 워크스페이스 (Team Workspace / Invite Team)

- 팀원 초대, 캠페인 전체 가시성 공유
- 브리프 할당, 콘텐츠 승인 라우팅, 결제 공동 관리

### 3.7 크리에이터 CRM (Bring & Manage Creators)

- **플랫폼 밖에서 이미 협업 중인 크리에이터를 초대**해 마켓플레이스 고용 건과 동일한 브리프·결제·추적 워크플로우로 관리
- "One roster, full visibility" — 외부 크리에이터 로스터까지 흡수하는 락인 전략

### 3.8 주문 라이프사이클 & 운영 정책 (공식 Knowledge Base 검증)

추가 점검에서 확인된 실제 운영 규칙. 클론 구현 시 상태머신 설계의 기준이 된다.

**주문 흐름 상태머신**
```
[브랜드] 패키지 구매 or 커스텀 오퍼 생성
   → 결제 즉시 선승인(캡처) — Stripe 처리
[크리에이터] 72시간 내 수락/거절
   ├─ 거절 → 즉시 브랜드 잔액(balance)으로 환불
   ├─ 만료 → 자동 환불 + 크리에이터 프로필 랭킹 페널티
   └─ 수락 → 에스크로 예치, 상태: In Progress
[크리에이터] 콘텐츠 제출 (플랫폼 내 업로드)
[브랜드] 72시간 내 검토
   ├─ 승인 → 대금 지급, 주문 완료, 리뷰 작성 가능
   ├─ 수정 요청 → 크리에이터 재제출 (반복)
   └─ 무응답 72시간 경과 → 자동 승인 + 주문 종료
```

**세부 정책**
- **결제 인프라 이원화**: 브랜드 결제(pay-in)는 **Stripe** (PCI DSS Level 1, 암호화·토큰화), 크리에이터 지급(pay-out)은 **Dots.dev** (글로벌 지급 대행) — 승인 시 크리에이터의 플랫폼 내 잔액(balance)에 적립 → 크리에이터가 원할 때 인출하는 2단계 구조
- **지급(인출) 수단**: PayPal, 기프트카드(Amazon·Visa 등), 150+ 통화 현지 은행 이체, 모바일 월렛. 크리에이터 페이지는 "instant payouts" 표방
- **수정(리비전) 정책**: 원 주문 요구사항 범위 내라면 **무제한 수정 요청 가능**
- **자동 승인**: 브랜드가 제출 후 72시간 내 액션이 없으면 콘텐츠 자동 승인 및 대금 지급 — 크리에이터의 "무한 대기" 방지 장치
- **주문 취소**: 어느 쪽이든 취소 요청 가능하나 **양측 합의 필요**, 해결 전까지 대금은 에스크로 유지. 분쟁 시 Collabstr 지원팀이 중재
- **환불 크레딧**: 취소/환불 금액은 즉시 브랜드 계정 잔액으로 반환, 새 주문에 바로 재사용 가능
- **주문 금액 변경**: 진행 중 주문의 범위 변경 시 플랫폼 내에서 가격 수정 요청 가능
- **멀티 크리에이터 장바구니**: 여러 크리에이터의 패키지를 담아 한 번에 결제
- **크리에이터 지급 수단**: PayPal, Venmo, 은행 이체 등 현지 통화 지급

**크리에이터 온보딩·검증 프로세스**
- 가입 무료이나 **신용카드 등록 필수** — 평상시 과금 없음. 단 정책 위반 시(예: 제품만 수령하고 콘텐츠 미납품) 카드에 비용 청구 가능한 담보 성격의 안티프로드 장치
- **계정 배타성**: 동일 이메일로 크리에이터·브랜드 계정 동시 보유 불가(전환 시 기존 계정 삭제 필요), 활성 주문이 있으면 계정 삭제 불가
- 프로필은 **심사 1~3영업일**, 전원 승인 아님. 콘텐츠 품질이 기준 미달이거나 참여율이 유사 계정 대비 낮으면 거절
- 거절돼도 프로필 링크 직접 공유는 가능하나 **공개 마켓플레이스 리스팅에서 제외**
- 완료 주문·리뷰·브랜드 관계가 계정에 누적되어 평판 자산(트랙 레코드)이 됨

## 7. SEO / 그로스 전략 분석

Collabstr 성장의 상당 부분은 **프로그래매틱 SEO**로 설명된다.

1. **크리에이터 프로필 = 랜딩 페이지**: 110만 개의 인덱싱 가능한 고유 URL. 각각 완전한 메타 태그, canonical, 구조화된 콘텐츠 보유
2. **카테고리 허브 페이지**: `/top-influencers/instagram`, `/top-influencers/fashion` 등 "[플랫폼/니치] 인플루언서 찾기" 롱테일 키워드 공략
3. **무료 도구 페이지**: 가격 계산기, 가짜 팔로워 체커, 다운로더 등 검색량 높은 유틸리티로 유입 → 본 서비스 전환
4. **콘텐츠 자산**: 블로그의 단가 리포트(예: "Instagram Reels 평균 $288, 마이크로 인플루언서 평균 $198/포스트")가 업계 인용 소스가 되어 백링크 확보
5. **내부링크 그물**: 프로필 하단 Related Categories → 카테고리 페이지 → 개별 프로필 순환 구조

## 8. 강점 · 약점 (외부 리뷰 교차 검증 포함)

### 강점
- **가격 투명성**: 사전 공개 패키지 가격으로 예산 수립·비교가 즉시 가능, 콜드 DM/이메일 협상 마찰 제거
- **에스크로 신뢰 장치**: 업계 최대 페인포인트(사기·미지급) 해결
- **올인원 워크플로우**: 검색→브리프→협상→승인→결제→리포팅 통합, 툴 파편화 제거
- **낮은 진입 장벽**: 무료 검색·무구독 첫 주문, 계약·락인 없음
- **양방향 매칭**: 정찰제 직접 고용 + 캠페인 공고(역경매) 병행

### 약점 (외부 리뷰 소스 지적)
- **높은 실효 수수료**: 브랜드 10%(또는 5%) + 크리에이터 15% = 합산 20~25%. 유료 구독 중에도 거래 수수료가 붙는 점에 대한 불만 존재
- **크리에이터 품질 편차**: 가짜 팔로워·참여 조작 검증이 궁극적으로 브랜드의 실사(due diligence) 몫이라는 지적. 가짜 인플루언서 관련 사용자 불만 보고됨
- **크리에이터 측 경쟁 심화**: 공급 과잉으로 저가 경쟁 압력
- **오디언스 데이터 신뢰도**: 팔로워·타겟 정보의 불명확성 지적 사례 존재 (실제 분석 대상 프로필도 헤더 팔로워 "0.0k" vs 분석 섹션 "1.5M" 등 표기 불일치 관찰됨)
- **공개 API 부재**: 서드파티 통합 확장성 제한
- **크리에이터 가격 책정 지원 부재**: 크리에이터가 스스로 단가를 "감"으로 정해야 하는 구조

## 10. 검증 노트 (3회 점검 결과)

**1차 점검 — 공식 소스 간 대조**
- 프로필 페이지, 홈페이지, 가격 페이지 3개 공식 소스의 수치 일치 확인: 크리에이터 1.1m+, 수수료 10%/5%/15%, 플랜 가격 $249·$333(연간 기준) ✓
- 기능 7단계 워크플로우 명칭·설명 일치 ✓

**2차 점검 — 외부 소스 교차 검증**
- 수수료 구조(브랜드 10%, 크리에이터 15%), 에스크로 방식, 크리에이터 무료 입점: 외부 리뷰 소스들과 일치 ✓
- 불일치 발견: 외부 소스 일부는 "20만+ 크리에이터", "유료 플랜 $299~$399/월"로 기재 → 구 데이터로 판단, **공식 사이트 최신 수치(110만+, $249/$333 연간 결제 기준) 채택**. 월간 결제 시 가격은 이보다 높을 수 있음(연간 결제 시 2개월 무료 명시)

**3차 점검 — 내부 정합성·한계 명시**
- 분석 대상 프로필의 데이터 불일치 발견 및 본문 반영: 헤더 팔로워 "0.0k" vs 분석 섹션 "1.5M / 250k 평균 조회 / 5.0% 참여율", 헤더 리뷰 "1건·5.0" vs 리뷰 섹션 "5건·4.9" → 분석 섹션·리뷰 일부는 **비로그인 사용자용 샘플/플레이스홀더 데이터**로 추정됨(가입 유도 게이트와 일관). 실제 수치로 인용하지 않도록 주의
- 본 문서의 규모 지표(500k 브랜드 등)는 Collabstr **자체 공개 마케팅 수치**이며 제3자 검증 값이 아님
- 가격·수수료는 변동 가능하므로 구현 시점에 공식 페이지 재확인 권장

**4차 점검 — 크리에이터 측 & 온보딩 (공식 Knowledge Base + /creator 페이지)**
- 신규 확인: 크리에이터 가입 시 신용카드 필수(안티프로드), 프로필 심사 1~3영업일 및 거절 정책, 거절 시 마켓플레이스 미노출(직접 링크 공유는 가능), 지급 수단(PayPal/Venmo/은행 이체, 현지 통화)
- 외부 리뷰의 "팀 기능 없음(no multi-seat)" 주장 발견 → 공식 사이트의 Team Workspace 기능 명시와 **모순** → 구버전 리뷰로 판단, 공식 소스 채택

**5차 점검 — 주문 운영 정책 (공식 Knowledge Base)**
- 신규 확인: Stripe 기반 결제(PCI DSS Level 1), 크리에이터 수락 기한 72시간(만료 시 환불+랭킹 페널티), 브랜드 검토 기한 72시간 후 **자동 승인**, 원 요구사항 범위 내 무제한 수정, 취소는 양측 합의제+지원팀 중재, 환불은 계정 잔액 크레딧으로 즉시 반환, 멀티 크리에이터 장바구니 일괄 결제
- 외부 리뷰의 "48시간 검토 기한" 주장 → 공식 KB의 **72시간**과 불일치 → 공식 소스(72시간) 채택
- 미확인 잔여 항목(공식 문서 미발견): 크리에이터 지급 소요일(정산 주기), 사용권(usage rights)의 표준 계약 조항 원문, 분쟁 중재의 구체적 판정 기준, AI 브리프 생성의 내부 동작 — 구현 시 자체 정책 설계 필요 영역

**6차 점검 — 지급 인프라 & 잔여 미확인 항목 해소 (최종)**
- **정산 주기 미확인 항목 해소**: 승인 → 크리에이터 플랫폼 잔액 적립 → 자율 인출의 2단계 구조 확인. 지급 대행은 **Dots.dev**(Stripe와 별도), 인출 수단은 PayPal·기프트카드·150+ 통화 은행 이체·모바일 월렛
- 카드 등록 정책 상세 확인: 평상시 미과금, 정책 위반 시에만 청구되는 담보 구조. 일부 검증 절차는 최대 3주 소요 가능
- 계정 정책 확인: 크리에이터↔브랜드 계정 동일 이메일 병행 불가
- **부정 리뷰 리스크 재확인**: 외부 소스에서 가짜 인플루언서 불만, 고객지원 미흡, 지급 후 회수(clawback) 관련 사용자 불만 사례 존재 — 플랫폼 신뢰 운영(검증·CS·분쟁 처리)이 클론 서비스의 핵심 차별화 기회임을 시사
- **여전히 미확인**: 사용권 표준 계약 원문, 분쟁 판정 세부 기준, AI 브리프 내부 동작, 크리에이터 검증(vetting)의 정량 기준 — 공식 미공개 영역으로 판단, 구현 시 자체 설계 필요
- 한국 시장 서술(레뷰·마켓잇 등 체험단 중심 구도)은 일반 업계 이해 기반의 방향성 제시이며, 사업 착수 전 국내 경쟁사 최신 기능·요율 실사 별도 권장

**최종 판정: 진행 가능.** 기능 정의·수수료·주문 라이프사이클·결제/지급 인프라 구조가 공식 소스로 검증 완료되어, 이 문서를 요구사항 분석의 기준(baseline)으로 사용해도 무방하다. 미확인 4개 항목은 Collabstr를 모방할 수 없는 영역이 아니라 자체 정책으로 설계해야 하는 영역이다.
